# Audio Samples for AGMS-ILRMA Speech Enhancement

This repository contains audio samples comparing the untreated microphone input with representative speech enhancement outputs from AGMS-ILRMA and AGMS-ILRMA + FW-RCSCME at source distances of 3, 5, 10, and 15 m.

You can play the audio samples online [here](https://jinxuanteh.github.io/audio-sample-AGMS-ILRMA/).
