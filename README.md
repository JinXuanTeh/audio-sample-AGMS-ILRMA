# Audio Sample AGMS-ILRMA

Static listening gallery for speech enhancement examples comparing:

- Raw microphone input
- AGMS-ILRMA
- AGMS-ILRMA + FW-RCSCME

The gallery includes short male and female speech examples at 3 m, 5 m, 10 m, and 15 m.
